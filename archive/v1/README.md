# Archived implementation

This folder preserves the previous `lexi_ai` implementation, tests and examples
as they existed in the working tree at promotion time. Previously deleted files
were not restored. This code is historical reference, not installed, tested or
imported by the current package.

The active library is `lexi_ai`, exporting `Lexicon`. No compatibility layer with
this archive or the former `lexi_ai_v2` package is provided.
